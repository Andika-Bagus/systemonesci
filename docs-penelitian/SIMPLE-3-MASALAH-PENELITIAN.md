# 🔬 POIN 3: MASALAH PENELITIAN ITM SCI

## 🤔 MENGUBAH MASALAH BISNIS JADI PENELITIAN

### Masalah Bisnis:
"PT Syntax monitoring 222 website manual 4 jam/hari, tidak efisien, berisiko domain loss"

### ⬇️ Jadi Masalah Penelitian:
"Bagaimana cara bikin sistem monitoring terpadu yang bisa tingkatkan efisiensi 87.5% dengan tetap aman dan mudah dipakai?"

## ❓ PERTANYAAN PENELITIAN

### Pertanyaan Utama:
**"Bagaimana merancang sistem monitoring ITM SCI yang bisa capai 87.5% efisiensi improvement untuk 222 website + 132 OJS PT Syntax?"**

### Pertanyaan Detail:

1. **Requirements:** Apa kebutuhan sistem untuk monitor 222+ website dalam 1 platform?

2. **Security:** Bagaimana bikin dual authentication yang aman tapi mudah dipakai?

3. **Integration:** Bagaimana integrasikan API third-party (PagePilot, WHOIS) yang reliable?

4. **Performance:** Bagaimana pastikan sistem cepat (<3 detik) untuk 222+ website?

5. **Effectiveness:** Seberapa efektif ITM SCI capai target 87.5% improvement?

## 🎯 TUJUAN PENELITIAN

### Tujuan Utama:
Bikin sistem ITM SCI yang proven bisa tingkatkan efisiensi monitoring dari 240 menit jadi 30 menit per hari.

### Tujuan Spesifik:
1. **Analisis:** Pahami kebutuhan monitoring 222 website + 132 OJS
2. **Rancang:** Desain arsitektur Laravel + React yang optimal
3. **Bangun:** Implementasi sistem dengan 9 modul utama
4. **Optimasi:** Pastikan performance <3 detik + security enkripsi
5. **Evaluasi:** Ukur effectiveness dengan TAM survey + efficiency metrics

## 💡 KONTRIBUSI PENELITIAN

### Untuk Akademik:
- **Framework DSR:** Cara apply Design Science Research untuk monitoring systems
- **Evaluation method:** Metode ukur effectiveness sistem monitoring
- **Integration patterns:** Best practice integrasikan multiple APIs

### Untuk Bisnis:
- **Efisiensi:** 87.5% time saving untuk PT Syntax
- **Cost saving:** Rp 75+ juta per tahun
- **Template:** Sistem bisa diadaptasi company lain dengan masalah serupa
- **Security:** Encrypted credential management yang aman

### Untuk Industry:
- **Reference:** Contoh implementasi monitoring system yang working
- **Technology guide:** Laravel + React untuk monitoring platform
- **Best practices:** Integrasikan PagePilot + WHOIS dengan proper error handling

## 🔬 METODOLOGI PREVIEW

### Kenapa Pilih Design Science Research?
- ✅ **Problem-focused:** Solve real business problem PT Syntax
- ✅ **Artifact-based:** Bikin working system sebagai solution
- ✅ **Evaluation-heavy:** Must prove effectiveness dengan data
- ✅ **Practical impact:** Immediate business value + academic contribution

### 6 Langkah DSR:
1. **Problem identification:** Analisis masalah PT Syntax
2. **Define objectives:** Set target 87.5% efficiency
3. **Design & development:** Build ITM SCI system
4. **Demonstration:** Show working system ke stakeholders  
5. **Evaluation:** Measure effectiveness (TAM + performance metrics)
6. **Communication:** Thesis + knowledge sharing

## 📏 SCOPE & BATASAN

### Yang Termasuk:
- ✅ Monitor 222 website + 132 OJS instances
- ✅ Domain expiry tracking + automated alerts
- ✅ Performance monitoring (PageSpeed + uptime)
- ✅ Secure credential management dengan enkripsi

### Yang Tidak Termasuk:
- ❌ Automated website repair (hanya monitoring)
- ❌ Mobile native app (web responsive only)
- ❌ AI/ML predictions (basic monitoring only)
- ❌ Integration dengan WordPress/OJS backend

## ✅ EXPECTED RESULTS

### Hipotesis:
1. **Efficiency:** ITM SCI akan capai >80% time reduction
2. **Risk reduction:** Zero domain loss incidents
3. **User acceptance:** >4.0/5.0 TAM score
4. **Performance:** Sistem handle 222+ website dengan <3s load time

### Success Metrics:
- **Time:** 240 menit → 30 menit (87.5% improvement)
- **Detection:** 4 jam → 5 menit downtime detection
- **Incidents:** 2-3/tahun → 0 domain loss
- **Satisfaction:** >4.0/5.0 user rating
